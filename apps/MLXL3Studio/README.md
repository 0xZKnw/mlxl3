# MLXL3 Studio

The macOS SwiftUI application and its Swift package. [Package.swift](Package.swift) defines the executable target and the vendored SwiftMath target.

- [Sources/](Sources/README.md): interface, application model, conversation management, and engine bridge.
- [Resources/](Resources/README.md): bundled icons, metadata, and rendering resources.
- [Vendor/](Vendor/README.md): third-party components included in the repository.
- [scripts/](../../scripts/README.md) and [tests/](../../tests/README.md): Desktop packaging and checks.

A build, the installed app, and a published release are distinct states. See the [main README](../../README.md) and [Desktop reports](../../docs/desktop/README.md).
