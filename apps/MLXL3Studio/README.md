# MLXL3 Studio

Application macOS SwiftUI et son paquet Swift. [Package.swift](Package.swift) définit la cible exécutable et la cible SwiftMath vendue avec le dépôt.

- [Sources/](Sources/README.md) : interface, modèle applicatif, gestion des conversations et pont vers le moteur.
- [Resources/](Resources/README.md) : icônes, métadonnées et ressources de rendu embarquées.
- [Vendor/](Vendor/README.md) : composants tiers inclus dans le dépôt.
- [scripts/](../../scripts/README.md) et [tests/](../../tests/README.md) : assemblage et vérifications Desktop.

Le build, l’app installée et une release publiée sont des états distincts ; voir le [README principal](../../README.md) et les [rapports Desktop](../../docs/desktop/README.md).
