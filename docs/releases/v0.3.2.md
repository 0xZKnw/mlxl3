# MLXL3 Desktop v0.3.2

## Changes

- Faster first-token startup: cache immutable detokenizer vocabulary metadata while keeping each response's streaming state independent.
- Exact routing-permutation inversion without a second sort.
- Check prefix snapshot budgets before copying; reserve KV fork capacity appropriately.
- Check cancellation and memory pressure between prefill chunks.
- More detailed runtime timing and numerical/performance validation tools.

On the local M5 Qwen 35B-A3B test, median TTFT over three A/B pairs fell from
290 to 191 ms without prefix reuse and from 176 to 83 ms with prefix reuse.
These are workload-specific measurements, not a promised decode speedup.

Experimental Metal, cache and TensorOps tuning paths are included in source
but remain disabled by default. Some candidates failed numerical validation or
regressed in speed; they are not enabled in the released app.

## Install

Download the Apple Silicon DMG and drag **MLXL3 Desktop.app** into Applications.
The engine and Python runtime are included; model weights are not.
Requires Apple Silicon and macOS 26.2 or later. This build is ad-hoc signed,
not Developer ID notarized; macOS may require approval in Privacy & Security.
Existing installations can check GitHub updates in Settings.

## Validation

322 automated tests passed; two tests were skipped because their local model
fixtures were unavailable. The DMG checksum and app signature were verified,
and the bundled runtime generated tokens with LFM. Final bundled Qwen/Gemma
smoke testing was not completed: Qwen stalled in Metal amid local memory
pressure and the tests were stopped. This release does not claim that issue
is fixed or that every model was retested in the packaged app.
