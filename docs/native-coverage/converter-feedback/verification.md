Primary reference sources are MLX 0.32.2 [`mlx/utils.h`](https://github.com/ml-explore/mlx/blob/v0.32.2/mlx/utils.h), [`matmul.cpp`](https://github.com/ml-explore/mlx/blob/v0.32.2/mlx/backend/metal/matmul.cpp) and [`steel/gemm/nax.h`](https://github.com/ml-explore/mlx/blob/v0.32.2/mlx/backend/metal/kernels/steel/gemm/nax.h). The native kernel reuses the already qualified QSA cooperative 16x32x16 primitive and calls no MLX runtime. Explicit `--full-fp32`, the existing `MLX_ENABLE_TF32=0` compatibility flag, or an older supported device selects the separate SIMD FP32 implementation. Both protocols report their selected arithmetic. This does not assert that every possible MLX dispatch or arbitrary hardware uses the same reduction.

Seven end-to-end variants invoke the actual maintained advanced CLI in exited reference/candidate processes, with MLX imports forbidden in every candidate: K4/MCG identity at buffers 32 and 128; K4 computed scales/GSS at buffer 128; K4 computed scales with forced 1024/buffer 32 and 4096/buffer 128 transport budgets; K2 and K8 computed scales/buffer 128. Both direct and LDLQ modes reproduce complete checkpoint tensors and quantization metadata: 14 comparisons and 64,000 exact words, including scales. The ordinary boundary tests use explicit protocol doubles; they are not substitutes for these physical runs. The final full-FP32/tails smoke checks the retained masked shader against NumPy on 32,768 words and 15 exact integer words in each arithmetic at shape 3x7x5. Its raw report is retained; the historical inline command has no separate script snapshot.

The reusable device encoder owns no model state, accepts owned FP32 MatrixViews with signed source strides, and encodes into a distinct contiguous output. Each logical matrix is capped at 64M values/256 MiB. The host converter splits large products only across output rows and columns, retaining the entire K accumulation and aligned tile boundaries where possible. A 2432x248320 output is planned without allocation in tests, and actual CLI tests force both row and column slicing on small disposable matrices. A later-chunk failure never returns a partly filled product. Negative or strided **device** views remain unqualified by this slice; the CLI tests serialize strided host arrays into contiguous device uploads.

The process boundary shares bounded stdout/stderr, finite deadlines, cancellation and terminate/kill/reap handling with native trellis search. It rejects invalid reports, foreign shapes/arithmetic, boolean integers, missing/partial/nonfinite payloads, unexpected members, file and directory symlinks, silent or failed children and output floods. Publication remains exclusive and atomic through the existing native directory publisher. The capture identity reader also accepts valid epoch/pre-epoch file timestamps while rejecting booleans; it does not claim to implement a producer.
