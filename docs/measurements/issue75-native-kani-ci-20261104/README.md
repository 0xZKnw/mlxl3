# Bound existing core Kani contracts without changing input domains

In PR #113, CI run [41731429083](https://github.com/0xZKnw/mlxl3/actions/runs/41731429083) timed out in three unchanged core harnesses while CBMC kept unrolling `memcmp` thousands of times. This patch adds explicit unwind attributes: 8 for the cold-row literal parser, 8 for the MB34 role literal parser, and 128 for the MB34 role/shape scope check. It changes no production function, assertion, symbolic input, assumption, stub, or harness registration. Existing PR and main-push CI already discovers these harnesses.

The two literal checks retain their complete symbolic `u8` choice domains and original sets of absent, valid, and invalid literals. The shape check retains all `i32` input/output dimensions and all four roles at its original fixed layer-name strings. It does not prove every arbitrary prefix string. Unwinding assertions remain active.

After rebasing onto main `17c66327`, real-source bounded model checks through an edition-2024 Cargo wrapper pass 292 obligations and 12/12 covers: 70/3 for cold rows, 79/5 for MB34 role literals, and 143/4 for shapes. The shape check has one unreachable standard formatting-overflow assertion. The full three-module Rust test suite passes 104 tests, with zero failures or ignored tests. The actual repository modules are included directly; the wrapper does not rewrite their functions. Commands, source identities, raw-log hashes, and preserved failures are in [result.json](result.json). The `*-main17c.summary.log` files contain the final proof summaries; earlier summaries remain preserved.

Main also omitted two existing NT2 selector/grid names from the test's exact manifest oracle. The original test is reproduced at its set-equality assertion, then passes after adding those two already-registered names. Ruff format and lint pass. The ordinary pytest invocation explicitly skips 44 Linux/prlimit process cases on this Mac; the affected fixture-only test is also invoked directly. CrossHair was attempted on that actual test but could not import pytest from the existing formal environment, so symbolic verification remains unavailable.

The initial standalone proof invocation used Rust's default 2015 edition and failed compilation; the Cargo wrapper fixes its context to the production edition. The first Flash wrapper lacked libc, and the initial ordinary-test wrapper lacked serde_json; those failures and corrected invocations are retained. A separate attempt at the unchanged Flash failed-fill harness with CLI unwind 64 timed out after 120 seconds. Its source stays at 27. The original Flash CI result also contains two standard slice-fill unwinding errors, rather than a discovered dead-object violation.

Existing grouped-route 8/80 and two-route cache CI timeouts remain outside this patch. The core shard previously exhausted its aggregate budget; the targeted checks do not establish full CI success. Whole-engine builds, Clippy, and physical GPU checks are not repeated for these proof-only attributes: production functions are unchanged, and the existing hosted checks remain applicable to the new PR commit.

No GPU trial, model result, or throughput claim follows from this repair. Raw original CI and local logs are retained in `build/kani-ci-bounds`; the public report preserves hashes and stable GitHub job links if local build files later disappear.
