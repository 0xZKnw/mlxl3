## S1 — paired finishes, not expert encoder reuse

Strata's [moe.metal173–205](https://github.com/Niko1221/Strata/blob/ffa80d73133ea5c548aefe57889a16e8085a938f/metal/kernels/moe.metal#L173-L205) computes gate/up and SwiGLU together. Native [projection.rs1104–1121](../../../native/src/gpu/projection.rs#L1104) currently finishes each QMV separately, then launches SwiGLU. The local canonical boundaries are [finish128, exl3.metal136–151](../../../native/shaders/exl3.metal#L136) and [Half SwiGLU157–164](../../../native/shaders/exl3.metal#L157).

Smallest independent adaptation: leave both input transforms and QMV tile bodies unchanged; fuse **both output Hadamards/scales/Half conversions plus Half sigmoid/product** into one final kernel. Preserve the ordered split sum, intermediate Half rounding, each matrix's svh and bias behavior. This is a new math-preserving kernel boundary, not the canceled same-encoder scheme and not old T04's SwiGLU→down fusion. Do not copy Strata's GGUF arithmetic.

The routed scratch mode currently overwrites the same partial buffer gate→up. Simply delaying gateFinish would corrupt it. Retain gate/up partials in **two checked disjoint ranges** of the existing10240B arena where they fit; bind offsets, otherwise use canonical fallback. No new allocation/copy may be hidden. Two finish launches plus activation become one per eligible expert invocation: structural ceiling1056dispatches/row at48×11experts, subject to actual eligibility counters, not measured time. Separate gate/up Half outputs can disappear while canonical casts remain explicit.

Oracle: independent stock EXL3 projection outputs and canonical Half SwiGLU, including finiteHalf/subnormal/signed-zero/overflow boundaries, K2/K4 formats and nonzero offsets. Reuse the routed scratch fixture and real records, compare nonempty finite outputs; mutate one gate factor/range to prove rejection. Production geometry/offset Kani on actual helpers, no shader proof claim. Then the existing four-step full-logit/hidden/84-state/continuation model and real CLI gate before MAIN32. History: [T04/PR61 scope](../../../opti.md#L23393), [scratch adaptation audit](../../../opti.md#L24557); new reason is the native two-finish boundary and bounded disjoint raw storage, not re-running their old path.

## S2 — reuse immutable-record storage only after its old generation is done

Strata allocates [one stable no-copy arena and slot addresses, stream.cpp460–474](https://github.com/Niko1221/Strata/blob/ffa80d73133ea5c548aefe57889a16e8085a938f/metal/src/engine/stream.cpp#L460-L474); its [victim guard258–269](https://github.com/Niko1221/Strata/blob/ffa80d73133ea5c548aefe57889a16e8085a938f/metal/src/engine/stream.cpp#L258-L269) excludes active/pinned entries. This storage mechanism is separate from global eviction policy.

Our native [start_shared321–340](../../../native/src/ssd_reads.rs#L321) allocates a fresh1,248,012B Shared buffer for every cold record; [moe.rs266–280](../../../native/src/gpu/moe.rs#L266) discards the victim views before submitting new reads. P01 deliberately introduced fresh exclusive destinations and excluded pools. New reason: full-native fixed-size direct-record lifetime is now available; a same-policy record pool avoids the seven-bank MLX scatter/layout architecture rejected by POOL04.

Bounded first variant: depth0/no-prefetch only; preserve each layer's53slot LFU, total capacity, reads, generations and byte offsets. After all old GPU uses are Completed and old projection views are retired, move the vacated backing to the worker; publish only after the whole read succeeds. Fresh allocation remains fallback if liveness/exclusivity is uncertain. Timeout/EOF must not return a physically active destination to the free list. No mlock/residency-set enrollment or cache-policy change is part of this candidate; it is not L5's HC workspace or UAR's fixed residency.

Target is cold-record allocation churn (the earlier corrected profile has1097misses across7rows); saved requested bytes/API calls are not saved RSS, NAND time or throughput. Meaningful tests: hold old GPU use, attempt recycle and require fallback; poison old views, timeout/drop/short read/new generation, old command committed late, then exact recovery. Actual allocation/reuse counters must show successful reuse after warmup and unchanged logical/Metal budget. Reuse P01 IO/expert/model fixtures plus the existing four-step oracle/CLI, with default MoE deferral ON. Formal helper bounds/state checks cannot prove Metal resource lifetime. The source's `Buffer: Send+Sync` alone is insufficient ownership evidence.

## S3 — cold continuation encoded before CPU read completion

Strata [run_graph_seg, mtl_rt.mm1050–1083](https://github.com/Niko1221/Strata/blob/ffa80d73133ea5c548aefe57889a16e8085a938f/metal/src/mtl_rt.mm#L1050-L1083) encodes the segmented graph first, commits it, then uses GPU/host event handshakes at SSD boundaries; [Window::at_cut496–498](https://github.com/Niko1221/Strata/blob/ffa80d73133ea5c548aefe57889a16e8085a938f/metal/src/engine/window.cpp#L496-L498) invokes streaming. Native [moe.rscold loop](../../../native/src/gpu/moe.rs#L334) receives completed records before building their expert views and encoding each cold wave.

Distinct from UAR's *final producer→next-layer consumer wait*: this hides **cold expert CPU encoding** behind the still-running read. Smallest trial is one prebound cold continuation, not a cached whole-model graph: allocate/validate stable destinations, encode expert work behind a shared-event wait, launch IO, signal after the full generation is ready. Keep strong references and canonical mix order. Do not copy Strata's unretained command buffers or busy-spin. Publication remains blocked until every read and command status is checked.

This deliberately changes P01's no-view-before-completion contract, so merely moving a call is unsafe. Error/timeout/cancel must always unblock and join a queued GPU wait before returning; private next-state writes must be discarded on failure. A first deterministic component must hold IO, demonstrate that continuation is already submitted but cannot execute early, release and match canonical output; inject EOF/cancel and demonstrate no stranded command/event or publication. Only then four-step states/logits/rollback+CLI and MAIN32. Current profile lacks separate cold-encode timing: inclusive MoE wait27ms/row does not quantify recoverable time. This is high structural scope with lower implementation readiness than S1/S2.

## S4 — split the *record*, not another completion wave or more workers

Strata [read_part274–306](https://github.com/Niko1221/Strata/blob/ffa80d73133ea5c548aefe57889a16e8085a938f/metal/src/engine/stream.cpp#L274-L306) can divide one expert into disjoint pieces for workers; [READ_SPLIT151–152](https://github.com/Niko1221/Strata/blob/ffa80d73133ea5c548aefe57889a16e8085a938f/metal/src/engine/stream.cpp#L151-L152) defaults to1. Our new common queue still gives a worker an entire [Read::run](../../../native/src/ssd_reads.rs#L127). It balances records, not an indivisible last record.

A discriminating future variant is **two page-aligned pieces only when a cohort has one or two large misses**, same four workers and total logical bytes, one generation completion after both succeed. Avoid a split-count tuning grid. Shared-destination subranges must be proved disjoint and cannot publish a half-filled expert. No extra GPU wave, UAR queue retest, late reads or cache enlargement. Strata's optional path is not evidence that the SSD/OS will improve; more syscalls can lose.

First IO oracle compares exact bytes across odd/page-boundary offsets, positive partial reads, EOF and failures in each piece; hold one piece and reject early publication/reuse, then join/recover after timeout/drop. Kani checks actual interval and completion-state arithmetic, not OS concurrency. If component latency/tail evidence is unfavorable, retain the negative without forcing a model run; if promising, existing P01 independent expert/model+CLI gate precedes MAIN32. Old [71 split-GU/down history](../../../opti.md#L19004) was projection-phase IO/compute overlap, not parallel subranges of the same whole record; old [59 aligned staging](../../performance/flash-dflash/flash-next-ssd-strata-splash-59-2026-10-21.md#L125) added copies/page-border bytes. Neither validates this new native direct-destination variant.

## Not counted as new strong candidates

Global shared expert eviction remains absent natively: Strata [size-class budget403–420](https://github.com/Niko1221/Strata/blob/ffa80d73133ea5c548aefe57889a16e8085a938f/metal/src/engine/stream.cpp#L403-L420) differs from48independent caches. However [POOL01](../../../opti.md#L20424) replays and [POOL04 audit/rejection](../../../opti.md#L20656) already found no general benefit; ARC slowed decode3.48/2.15% and uniform shared banks were inconclusive. A native zero-copy global pool could remove old MLX insertion overhead, but must first replay current captured routes at identical2544slots, exact initial state and fixed policy; it is not a fourth established win or justification to rerun ARC blindly.

Strata's [shared/router sibling dispatches1142–1227](https://github.com/Niko1221/Strata/blob/ffa80d73133ea5c548aefe57889a16e8085a938f/metal/src/engine/window.cpp#L1142-L1227) motivate early-shared scheduling. Native shared already overlaps demanded cold IO; [73 history](../../../opti.md#L18091) is heterogeneous and not promoted. This is not counted. Demand-priority/cancel of prefetch pieces concerns depth>0 and is not a missing depth0 budget. Strata's `run_icb` is tooling, not proof its AR production path replays an ICB; it is not counted. Existing UAR common queue, fixed residency, GDN cast/norm and late MoE wait are not relabeled.

All quantities above are source counts or existing diagnostic observations, not new measurements. Only this note was authored; root owns selection/journal and later executable qualification.
