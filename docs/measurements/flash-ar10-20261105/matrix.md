At least ten distinct trials are the target; A07/A06 are the largest ports and cannot be mislabeled successful if parity or integration fails. Two variants of one row never inflate the count. Strata's SharedEvent cold continuation is a separate reserve, not silently counted: committing a GPU wait before an uncancellable pread creates timeout/ownership risks; an uncommitted pre-encoding adaptation would need its own state protocol first. Shared global cache/ARC remains a historical negative, not a new quick win.

Protocol: each row starts OFF, exactM5/shape/capability qualified where appropriate. Read and follow formal-proof-skill/Rust/Metal(C++) reference before code. Add only meaningful regression/boundary/error checks and actual-path counters; attempt Kani on real guards/offset/ownership helpers, never claim shader/concurrency proof. Existing independent fixtures and full state archive are the oracles. Build once per coherent ready batch; no model GPU with compilers/provers/other inference. Components are qualified before microbenchmark; a common state/logit/hidden/CLI gate covers qualified model paths before MAIN32 timing. Existing frozen PR130 reference plus same-binary OFF controls, cache3GiB/48×53/readers4/depth0/prefixOFF/T0K1/penalty1, one warm+one measured32generated/31decode short screens. Alternate/control endpoints or repeat only affected uncertain decisions; no arbitrary minimum gain and no adding percentages. Keep compatible small candidates for a measured composition, audit adaptation before rejection, retain raw failures and classify inconclusive separately from rejected. No swap abort, app replacement, merge or release. Publish qualified work in PR per user's standing request.
