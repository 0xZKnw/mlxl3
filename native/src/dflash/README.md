# Tests DFlash gérés

[managed_tests.rs](managed_tests.rs) complète le module parent [dflash.rs](../dflash.rs) et vérifie notamment la gestion des modèles et fichiers DFlash dans des répertoires de test temporaires. Les kernels associés sont dans [native/shaders/](../../shaders/README.md). Les tests de gestion ne remplacent pas une validation de génération sur modèle physique.
