# Relecture de cache Flash

[profile53.rs](profile53.rs) rejoue des accès à froid puis à chaud ; [shared.rs](shared.rs) et [shared/](shared/README.md) évaluent des politiques de slots partagés hors ligne. Le module parent est [flash_cache_profile.rs](../flash_cache_profile.rs). Ces simulations ne reconstruisent pas toutes les conditions physiques du cache et ne modélisent pas les buffers GPU ni les baux en vol.
